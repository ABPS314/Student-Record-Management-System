# Student Record Management System

A menu-driven Student Record Management System developed using C.

## Features
- Add student records
- Display all student records
- Search student records
- Modify student details
- Delete student records
- Sort records
- Save records to a file
- Load records from a file

## Technologies Used
- C Programming
- Structures
- Pointers
- Singly Linked Lists
- Dynamic Memory Allocation
- File Handling
- Makefile

## Build and Run

Compile: `make`

Run: `./out`
